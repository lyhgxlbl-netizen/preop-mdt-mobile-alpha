# 术前风险评估与 MDT 会诊工作台

v0.10.0 Respiratory Candidate Layer 的公开测试静态站点。

本页面仅用于教学和院内流程验证，不替代临床判断，不保存患者数据。公开测试不得输入真实可识别患者信息。

医学知识状态：AKB V2.1.1，临床门禁 `locked_review_pending`。

v0.7 加入独立的 SORT 外部结果、DASI、CFS/FRAIL 既有分数，以及 BNP/NT-proBNP、肌钙蛋白和 ECG 风险修饰因子记录。所有补充层仍为 `candidate/in_review`：不运行 SORT，不复制完整量表，不合并总分，也未启用新的自动临床规则。

v0.7.1 加入可点击和键盘操作的翻转卡片。背面显示方法概要、官方入口和版权/许可状态；完整问卷、译文、计分权重及 SORT 模型系数继续保持锁定。

v0.7.2 在DASI翻转页加入非官方教学速览，包括12类活动的重新表述、研究权重和功能容量估算公式；不提供正式问卷施测或自动计分。

v0.7.3 在SORT翻转页加入2014年原始模型的变量、参照组、回归系数和30天死亡概率转换；明确区别于当前SORT v2，不提供本地自动计算。

v0.7.4 在老年脆弱性翻转页加入CFS 1–9级与FRAIL五领域的非官方教学速览；明确二者方法不同，不复制官方图示/正式中文译本，不提供自动计分或临床规则。

v0.8.0 将手机端9个连续章节收拢为5步引导流程，加入置顶进度、直接跳转和底部上一步/下一步；桌面端、医学字段、规则、报告与MDT逻辑保持不变。

v0.9.0 新增“学员模式＋教师模式”：学员先完成独立判断并提交当前页面内存快照，随后解锁教学提示与教师形成性评价。四维评分和监督级别均由教师人工记录，不自动判定合格；退回修改、重置或刷新会清除快照与反馈。

v0.10.0 新增 `candidate/in_review` 呼吸风险补充层：基础呼吸筛查、按需肺功能和动脉血气既有结果、检查选择理由及管理影响进入学员快照、报告和 MDT 草稿；教师评价增加“呼吸风险识别”。不新增自动阈值、常规必查、转诊、MDT触发或手术决定。
